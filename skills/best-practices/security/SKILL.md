# Skill: Security

Sempre considerar segurança no código.

## Regras

- validar todos inputs
- nunca confiar em dados externos
- evitar exposição de secrets
- sanitizar dados de usuário

## Evitar

- SQL injection
- XSS
- exposição de tokens
